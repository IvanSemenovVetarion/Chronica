# Chronica для Android

Android-версия Chronica 2.0.1 — это тот же интерфейс в нативной оболочке WebView.
Она рассчитана на телефоны и планшеты, работает без интернета и хранит данные
внутри приложения.

## Установка

1. Скачайте `Chronica-Android-2.0.1.apk` из раздела Releases.
2. Разрешите установку приложений из этого источника в настройках Android.
3. Откройте APK и установите Chronica.
4. Запустите приложение и выберите язык, жанр и стиль.

Минимальная версия: **Android 7.0 (API 24)**. Рекомендуется Android 10+.
APK собран как debug-сборка и подписан тестовым ключом. Для Google Play нужна
отдельная release-подпись.

## Где хранятся данные

Внутри приложения:

```
/data/user/0/com.vetarion.chronica/files/ChronicaData/
```

Там лежат:

- `chronica.json` — миры, герои и летопись;
- `chronica.json.bak` — предыдущая рабочая копия;
- `images/` — портреты, галерея, фон и карта;
- `audio/` — голос и музыка;
- `fonts/` — свои шрифты;
- `backups/` — внутренние ZIP-копии.

Начиная с Android 11 доступ к этой папке из файлового менеджера ограничен.
Для переноса используйте экспорт через системный выбор файлов.

## Перенос между Android и Windows

Формат данных один и тот же — `chronica.json`. Изображения и аудио нужно
переносить архивом.

### Windows → Android

1. В Windows откройте **Настройки → Данные**.
2. Нажмите **Экспорт JSON** — для текста без изображений.
   Или **Сохранить копию** — ZIP с изображениями, аудио и шрифтами.
3. Передайте файл на телефон: USB, облако, мессенджер.
4. В Android откройте **Настройки → Данные → Восстановить** и выберите JSON
   или ZIP.

### Android → Windows

1. В Android откройте **Настройки → Данные**.
2. Нажмите **Экспорт JSON** или **Сохранить копию**.
3. Передайте файл на компьютер.
4. В Windows откройте **Настройки → Данные → Восстановить** и выберите файл.

JSON переносит только текст и ссылки на изображения. ZIP переносит также
изображения, аудио и шрифты. Ссылки на медиа внутри данных имеют вид
`https://media.mifarium/...` и работают в обеих версиях.

## Что есть в Android-версии

- все миры, персонажи, связи, древо, карта, лор, библиотека и заметки;
- добавление изображений, аудио, фона и шрифтов через системный выбор файлов;
- экспорт JSON и ZIP-резервной копии;
- восстановление JSON и ZIP;
- адаптивное меню: на телефоне — выдвижная панель, на планшете — обычная
  компоновка с уменьшенными отступами;
- светлая и тёмная темы, масштаб текста.

## Ограничения Android-версии

В Android-версии намеренно скрыты функции, которым нужен полноценный рабочий
стол:

- экспорт Word и Excel;
- совместная работа через общую папку;
- импорт DeepSeek;
- проверка и установка обновлений GitHub.

Эти функции остаются в Windows-версии. Для обновления Android-приложения
установите новый APK из Releases.

## Сборка APK

Нужны JDK 17 и Android SDK с платформой 35/build-tools 36.

```bat
cd android
gradlew.bat assembleDebug
```

Готовый файл:

```
android\app\build\outputs\apk\debug\app-debug.apk
```

Для сборки из корня проекта:

```bat
build-android.cmd
```

Скрипт копирует APK в `dist\Chronica-Android-2.0.1.apk`.

## Техническая схема

- `MainActivity.java` — WebView, системные панели, внешние ссылки и файловые
  запросы;
- `ChronicaBridge.java` — сохранение `chronica.json`, импорт/экспорт JSON и ZIP,
  выбор медиа, счётчики и данные о хранилище;
- `ui/` — общий интерфейс Chronica;
- `ui/mobile.css` и `ui/mobile.js` — адаптивная оболочка и выдвижное меню;
- медиа-файлы отдаются через те же адреса `https://media.mifarium/...`,
  `https://audio.mifarium/...` и `https://fonts.mifarium/...`, что и в Windows.

APK не содержит `ChronicaData` пользователя — данные создаются при первом
запуске.
