файле [`LICENSE`](LICENSE) относится к оригинальному коду и материалам проекта
Vetarion. Она **не заменяет** лицензии сторонних библиотек, шрифтов и товарных
знаков, перечисленных ниже.

## Microsoft Edge WebView2

В папке `vendor/` находятся файлы WebView2 SDK:

- `Microsoft.Web.WebView2.Core.dll`
- `Microsoft.Web.WebView2.WinForms.dll`
- `WebView2Loader.dll`

Версия: **1.0.4370.26**. Copyright (C) Microsoft Corporation. All rights reserved.
Компоненты распространяются по лицензии BSD 3-Clause и сопровождаются
уведомлениями Microsoft. Полные тексты:

- [`licenses/webview2/LICENSE.txt`](licenses/webview2/LICENSE.txt)
- [`licenses/webview2/NOTICE.txt`](licenses/webview2/NOTICE.txt)

Microsoft Edge WebView2 Runtime не входит в репозиторий и устанавливается
отдельно как компонент Windows. Актуальные условия:
<https://learn.microsoft.com/microsoft-edge/webview2/>.

Приложение собрано для .NET Framework 4.8. Среда выполнения не входит в
установочный пакет Chronica и предоставляется Microsoft как компонент Windows.
