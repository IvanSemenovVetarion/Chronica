# Безопасность

Chronica — локальное Windows-приложение. Оно не отправляет данные на серверы
без вашего действия. Ключ DeepSeek хранится локально и шифруется Windows DPAPI.

## Если вы нашли уязвимость

Пожалуйста, **не публикуйте** технические детали и данные пользователей в
открытом issue. Используйте GitHub Security Advisories:

1. Откройте вкладку **Security** репозитория.
2. Нажмите **Report a vulnerability**.
3. Опишите версию, шаги воспроизведения и ожидаемое поведение.

Если приватные advisories недоступны, напишите автору через профиль GitHub и
оставьте контакт для ответа.

## Что полезно приложить

- версию Chronica из `Настройки → О программе`;
- версию Windows и WebView2 Runtime;
- текст ошибки и, если возможно, фрагмент `ChronicaData\chronica.log`;
- скриншот без личных данных.

Никогда не прикладывайте:

- API-ключ DeepSeek;
- содержимое `settings.json`;
- личные документы, изображения и переписки.

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии.
Старые сборки могут не получать обновления.
