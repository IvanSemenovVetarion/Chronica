# Как помочь Chronica

Спасибо за интерес к проекту. Это небольшое Windows-приложение, поэтому
лучший вклад — точный отчёт об ошибке или аккуратный pull request.

## Сообщения об ошибках

Перед созданием issue:

1. Проверьте, что используется последняя версия из Releases.
2. Закройте Chronica и сохраните резервную копию данных.
3. Проверьте `ChronicaData\chronica.log`.
4. Приложите версию Windows и WebView2 Runtime.

Не прикладывайте личные миры, API-ключи и содержимое `settings.json`.

## Pull requests

- Одна тема — один pull request.
- Сохраняйте стиль существующего кода: C# 5, без интерполяции строк, `?.` и
  автосвойств; интерфейс — vanilla JavaScript без сборщика.
- Не добавляйте внешние зависимости без обсуждения.
- Для изменений интерфейса приложите скриншот до/после.
- Проверьте обе языковые версии, если меняете тексты.
- Не коммитьте `dist/`, `build/`, `backups/`, `ChronicaData/` и `ChronicaDnDData/`.

## Сборка

```bat
build.cmd
```

Требуются Windows 10/11 x64, .NET Framework 4.8 и WebView2 Runtime. Результат —
`dist\Chronica\Chronica.exe`, `dist\ChronicaSetup.exe` и
`dist\Chronica-portable.zip`.
